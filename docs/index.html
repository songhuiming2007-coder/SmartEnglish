Installation
Up and running in 2 minutes.
Follow these steps carefully. macOS has strict security settings for third-party input methods.请仔细按以下步骤操作。macOS 对第三方输入法有严格的安全限制。
1

Allow apps from anywhere

macOS blocks unsigned apps by default. Open Terminal and run:macOS 默认阻止未签名应用。打开 终端 并运行：

sudo spctl --master-disable

Then open System Settings (press Cmd+Space and search "Privacy & Security" to jump there directly), scroll down to "Allow apps downloaded from" and select Anywhere. You can change this back after installation.然后打开 系统设置（按 Cmd+Space 搜索 "隐私与安全性" 直接跳转），向下滚动到 "允许从以下位置下载的应用"，选择 "任何来源"。安装完成后可恢复此设置。

2

Download the installer

Click the Download .pkg button above to get SmartEnglish.pkg.点击上方的 Download .pkg 按钮下载 SmartEnglish.pkg。

3

Run the installer

Double-click SmartEnglish.pkg and follow the prompts. The installer automatically copies the app to ~/Library/Input Methods/ and removes quarantine flags. No Terminal commands needed.双击 SmartEnglish.pkg 并按提示操作。安装器会自动将应用复制到 ~/Library/Input Methods/ 并移除隔离标记。无需终端命令。

4

Add input source

Go to System Settings → Keyboard → Input Sources, click +, find English, select SmartEnglish, click Add.前往 系统设置 → 键盘 → 输入源，点击 +，找到 English，选择 SmartEnglish，点击 添加。

If SmartEnglish doesn't appear in the list, restart your Mac and try again.如果列表中没有 SmartEnglish，请重启 Mac 后重试。

5

Restart your Mac (if needed)

After adding the input source, you may need to restart for it to appear in the menu bar. This is a macOS limitation — the system caches input sources and a reboot forces a refresh.添加输入源后，可能需要重启 才能在菜单栏看到它。这是 macOS 的限制 — 系统会缓存输入源列表，重启可强制刷新。

After restart, click the input method icon in the menu bar (or press Ctrl+Space) to switch to SmartEnglish.重启后，点击菜单栏输入法图标（或按 Ctrl+Space）切换到 SmartEnglish。

6

Start typing!

Type a few letters in any app — a candidate window will appear. Press 1-9 to pick a word, Space to accept the top pick, Enter to commit raw text.在任意应用中输入几个字母 — 候选词窗口会自动出现。按 1-9 选择单词，空格 确认首选，回车 直接上屏原始文本。

3. Restart your Mac, then re-add the input source
