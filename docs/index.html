Installation
Up and running in 2 minutes.
Follow these steps carefully. macOS has strict security settings for third-party input methods.
1

Allow apps from anywhere

macOS blocks unsigned apps by default. Open Terminal and run:

sudo spctl --master-disable

Then go to System Settings → Privacy & Security, find "Allow apps downloaded from" and select Anywhere. You can change this back after installation.

2

Download the installer

Click the Download .pkg button above to get SmartEnglish.pkg.

3

Run the installer

Double-click SmartEnglish.pkg and follow the prompts. The installer automatically copies the app to ~/Library/Input Methods/ and removes quarantine flags. No Terminal commands needed.

4

Add input source

Go to System Settings → Keyboard → Input Sources, click +, find English, select SmartEnglish, click Add.

If SmartEnglish doesn't appear in the list, restart your Mac and try again.

5

Restart your Mac (if needed)

After adding the input source, you may need to restart for it to appear in the menu bar. This is a macOS limitation — the system caches input sources and a reboot forces a refresh.

After restart, click the input method icon in the menu bar (or press Ctrl+Space) to switch to SmartEnglish.

6

Start typing!

Type a few letters in any app — a candidate window will appear. Press 1-9 to pick a word, Space to accept the top pick, Enter to commit raw text.

Troubleshooting
遇到问题？
macOS 对第三方输入法限制较多，以下是常见问题和解决方法。
🚫

安装时提示"无法打开"

macOS 会阻止未签名应用。解决方法：
1. 打开终端，运行 sudo spctl --master-disable
2. 系统设置 → 隐私与安全性 → 选择 "任何来源"
3. 重新双击 .pkg 安装
安装完成后可恢复安全设置

🔄

输入法列表里找不到 SmartEnglish

安装后在系统设置的输入源列表中看不到：
1. 确认已运行 .pkg 安装器（不是只下载了）
2. 检查 ~/Library/Input Methods/ 目录是否有 SmartEnglish.app
3. 重启电脑，然后重新添加输入源
macOS 缓存输入源列表，重启是最可靠的解决方法

⌨

输入法显示为灰色 / 无法使用

添加输入源后如果显示灰色：
1. 完全退出系统设置
2. 重新打开系统设置 → 键盘 → 输入源
3. 如果仍不行，重启电脑
4. 重启后点击菜单栏输入法图标，选择 SmartEnglish

🔒

如何切换输入法

切换到 SmartEnglish：
• 按 Control + 空格 切换输入源
• 或按 地球键 (Globe key) 循环切换
• 或点击菜单栏输入法图标选择
注意：Caps Lock 只在英文和 ABC 之间切换，不包含自定义输入法

📄

候选词窗口不出现

确保已切换到 SmartEnglish（菜单栏显示 SE 图标）。输入英文字母后会自动显示候选词。按 1-9 选择，空格 确认第一个，回车 直接上屏原始字母。

🔄

更新或卸载

更新：下载新版 .pkg，双击安装即可覆盖
卸载：
1. 系统设置 → 键盘 → 输入源 → 移除 SmartEnglish
2. 删除 ~/Library/Input Methods/SmartEnglish.app
