Features
Everything you need,
nothing you don't.
A minimal, fast, privacy-first predictive text engine for macOS — now with smart casing and proper noun support.
⚡

Instant predictions

Candidates appear as you type, powered by a 50,000-word frequency dictionary. Sub-millisecond lookups, zero lag.

🌐

Works everywhere

Built as a native macOS input method — works in every app, from Safari to VS Code to Slack. No compatibility hacks.

🧠

Learns from you

SmartEnglish remembers your word choices and boosts them in future suggestions. Gets better the more you use it.

🎯

Keyboard-first

Press 1-9 to pick a candidate, Space to accept the top pick, Enter to commit raw text. Your fingers never leave the keyboard.

🪶

Featherweight

Under 3 MB memory footprint. No background processes, no telemetry, no network calls. Pure local computation.

🔒

Open source

MIT licensed. Read every line, fork it, improve it. Your input method should have nothing to hide.

✍️

Smart casing

Input case is preserved in output. Type ENG and get ENGLAND, type Eng and get England. No manual shifting needed.

🌎

Proper nouns

448 built-in proper nouns — countries, languages, and more. Type chin and SmartEnglish outputs China automatically.

Troubleshooting
遇到问题？
macOS 对第三方输入法限制较多，以下是常见问题和解决方法。
🔒

安装后无法打开

macOS Gatekeeper 会阻止未经验证的应用。解决方法：
方法一：右键点击 SmartEnglish.app → 选择「打开」
方法二：系统设置 → 隐私与安全性 → 允许从「任何来源」下载的应用

🚫

输入法显示为灰色

添加输入源后如果显示灰色无法使用：
1. 完全退出系统设置
2. 重新打开系统设置 → 键盘 → 输入源
3. 如果仍不行，重新登录或重启电脑

⌨

如何切换输入法

切换到 SmartEnglish：
• 按 Control + 空格 切换输入源
• 或按 地球键 (Globe key) 循环切换
• 或点击菜单栏输入法图标选择
注意：Caps Lock 在英文模式下是大写，不是切换输入法

📄

候选词窗口不出现

确保已切换到 SmartEnglish 输入法（菜单栏显示 SE 图标）。输入英文字母后会自动显示候选词。按 1-9 选择，空格 确认第一个，回车 直接上屏原始字母。

🔄

更新或卸载

更新：下载新版，双击 Install.command 即可覆盖安装
卸载：
1. 系统设置 → 键盘 → 输入源 → 移除 SmartEnglish
2. 删除 ~/Library/Input Methods/SmartEnglish.app
